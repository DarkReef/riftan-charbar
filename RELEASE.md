# Riftan Charbar 0.1.6

- Исправлено обновление запроса в Foundry 14: после ответа игрока исходная карточка сразу показывает степени успеха/провала. При наведении видны бросок/цель, заданные и изменённые поправки, источники состояний и снаряжения.
- Авторские ответы сохраняются для проверки владельца и видимости, но их отдельные карточки скрыты. Apex Heresy RU 1.7.1+ выполняет штатную проверку с `chat:false`, без дублирования результата в журнале.
- Изменение/удаление ответа и закрытие запроса обновляют исходную карточку и окно чата через `ChatLog.updateMessage`.
- Для нового ID системы требуется Apex Heresy RU 1.7.1+. Базовая совместимость прежнего `dark-heresy` 1.4.2+ сохранена; старый API без `chat:false` может публиковать дополнительную штатную карточку. Vendare не поддерживается.

Проверки: `npm test` — 16 успешно, 0 пропущено. Шесть новых регрессионных тестов выполняют настоящую точку входа модуля и обработчики Foundry; хранилище документов и DOM имитируются. Живой повторный прогон GM/игрока перед выпуском ещё требуется. Для слепых бросков локальная защита от повтора ограничена скрытой видимостью ответа; мастер принимает первый допустимый ответ.

Установка после публикации: https://github.com/DarkReef/riftan-charbar/releases/latest/download/module.json
